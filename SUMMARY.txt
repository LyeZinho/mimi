═════════════════════════════════════════════════════════════════════════════

✅ Hybrid Communication
   Event Bus (pub/sub) + Shared State (coordinated)
   
✅ Token Economy (70% Savings!)
   Only Brain 2 uses LLM
   Brains 1,3,4,5,6,7 use efficient algorithms
   
✅ Real-Time Performance
   Ring buffers, streaming TTS, async/await everywhere
   Target: < 300ms end-to-end
   
✅ "Nem Tudo é LLM" Philosophy
   Planning: rules (0 tokens)
   Sentiment: lexical (0 tokens)
   Avatar: mappings (0 tokens)
   Only reasoning uses LLM
   
✅ Modularity
   Each brain is independent
   Easy to replace implementations
   Subscribe to any event type

import asyncio

async def main():
    orchestrator = AgentOrchestrator(user_id="demo_user")
    
    await orchestrator.initialize()
    await orchestrator.start()
    
    await orchestrator.process_text_input("Olá Mimi!")

    metrics = await orchestrator.get_metrics()
    print(metrics)
    
    await orchestrator.stop()

asyncio.run(main())
