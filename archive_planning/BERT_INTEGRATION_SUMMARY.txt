================================================================================
COMO USAR
================================================================================

1. INICIALIZAR (STARTUP)
   - Engine criado em main.py: create_sentiment_engine()
   - Passado ao AgentOrchestrator via dependency injection
   - Inicializado durante orchestrator.initialize()
   - Carregamento: ~2-5 segundos (primeira vez)

2. ANALISAR TEXTO
   - SentimentBrain._analyze_sentiment(text) usa BERT automaticamente
   - Se BERT falha → fallback para lexical
   - Retorno: "happy" | "sad" | "neutral"

3. INTEGRAÇÃO AUTOMÁTICA
   - Avatar recebe sentimento do Bridge
   - Expressão muda baseado em sentimento
   - Sem código adicional necessário

4. FALLBACK AUTOMÁTICO
   Se engine não disponível:
   - Lexical matching automático
   - Zero downtime
   - Log warning (não crash)
